## 🆘 Troubleshooting

### Login fails?
```bash
# Clear browser storage
localStorage.clear()

# Verify backend running
curl http://localhost:5000/health

# Check credentials
Email: mathinachicken@gmail.com
Password: mathina
```

### Products not loading?
```bash
# Re-seed database
cd backend
npm run seed
```

### Port 5000 in use?
```bash
# Backend auto-frees port
npm run dev
```

### API calls failing?
```bash
# Check frontend .env
VITE_API_URL=http://localhost:5000/api
```
